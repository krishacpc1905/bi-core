# README #

This folder contains all codes of paper "A Unified Framework for Dense Subgraph Maintenance over Dynamic Bipartite Graphs".

## This folder contains the following: ##
* **index**: index code folder, index algorithm proposed in the paper, builds the index from the graph.
* **insert**: insert code folder, insert algorithm proposed in the paper, updates the index when edges are inserted to the graph.
* **delete**: delete code folder, delete algorithm proposed in the paper, updates the index when edges are removed from the graph.

More detailed README is in each subdirectory.
